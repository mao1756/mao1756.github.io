# Custom site notes

- Replace `assets/profile.jpg` with your headshot (square, ~800×800 recommended). It will auto-display on the home page.
- Header contact and social links are configured for: email `mnishino@fsu.edu`, LinkedIn, and GitHub (`mao1756`).
- Publications page will be updated by your existing workflow (SerpAPI/OpenAlex/Scholar). No changes required here.
- After changing the shared stylesheet or scripts, run `npm run version:assets` before publishing. This updates their content-based URLs on all three pages so returning visitors load the matching assets.
